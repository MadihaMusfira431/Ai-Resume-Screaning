# 🤖 AI Resume Screening System

This is a simple AI-powered resume screening application built using Streamlit and Python.

## 🚀 Features
- Enter required job skills
- Matches candidates based on skills
- Ranks candidates by match score
- Displays top candidates instantly

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas

## 📂 Dataset
The dataset contains:
- Name
- Skills
- Experience

## ▶️ How to Run

1. Clone the repository:
git clone https://github.com/your-username/Ai-Resume-Screening.git


2. Install dependencies:
pip install -r requirements.txt


3. Run the app:
streamlit run app.py
